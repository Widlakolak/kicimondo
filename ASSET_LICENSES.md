# Asset licenses

Stages 01–02 use original, temporary pixel art drawn from geometric shapes in code. There are no third-party game assets.

Record each asset before adding it to the repository or a distributed build:

| Asset/path | Author/source URL | License and version | Changes | Required attribution / notice |
| --- | --- | --- | --- | --- |
| [Location art](frontend/src/game/locationArt.ts), [bedroom map](frontend/src/game/maps/bedroom.tmj) and [landing map](frontend/src/game/maps/landing.tmj) | Original Stage 01–02 artwork and layouts authored in this repository with Codex | Project license pending | Temporary room, furniture and landing designs | No third-party attribution |
| [Avatar art](frontend/src/game/avatarArt.ts) | Original Stage 01 pixel shapes authored in this repository with Codex | Project license pending | Temporary portraits and walking frames | No third-party attribution |

For original placeholder assets, note their creator/provenance and whether they are temporary. For generated artwork, record the tool/source, date and relevant usage terms without exposing private prompts or personal information. Retain license text when required. Review fonts, icons, sounds, music, tilesets and sprite sheets separately. Dependency licenses are tracked independently through package metadata and notices.
