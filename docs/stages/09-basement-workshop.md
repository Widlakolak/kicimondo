The last six activities are fixed-slot recipes using their own one-time kit. Represent the crafting challenge through an existing age-appropriate puzzle (e.g. match shapes, order 3 illustrated steps, count pieces or trace a short path). Finishing the puzzle constructs the item in the world and awards one star. Do not require real-life tool use, electricity, blades, chemicals, ladders or unsafe basement exploration instructions; this is a safe brightly lit fictional space using prepared materials.

## Small crafting loop

- Six unique named/pictured kits, each earned by the corresponding preparation quest in the corridor/storage. The other three preparation quests need no material reward. A recipe has exactly one designated source quest and one destination fixed slot; no shared or competing scarce inputs, random loot, purchase, drop, grind, repeatable rewards or full inventory system. No need to gather materials in the old house/garden before opening the basement. No circular recipe dependencies.
- Define kit and recipe IDs as data. Prefer deriving availability/consumption from the validated completion ledger (source completed and recipe not completed) rather than a second mutable inventory. Use an explicit domain-level prerequisite on the crafting completion command; never allow an unearned recipe to complete merely through a stale UI or another tab. Commit the star and world restoration atomically with the recipe completion, derived kit consumption and any trust effects. Duplicate command/reload cannot consume or award twice.
- Child-facing UI shows picture of kit, "Masz" or "Znajdź", and a clear instruction to locate the source if absent. Make available recipe markers visually distinct from waiting-for-material icons, not color alone. A locked recipe can explain its source but must not be presented as an actionable star or launch the reward challenge. Guidance should point along accessible room transitions to the required source and not get stuck pointing to an inaccessible recipe. Once kit acquired, the recipe becomes a normal unfinished quest; on completion show the built prop and update the guidance. Provide a small picture-led kit view in the workshop/menu if needed, not a complicated resource dashboard.
- Add a sixth fictional resident cat, proposed name "Iskierka" (stable ID e.g. sparkle), in workshop; independently roams/rests, uses restored mat/hideout and suitable safe activities. New original portrait, silhouette, Kicipedia description and preferences. Discovery only when present and near; consent and trust from distinct appropriate interactions, no star from discovery/petting. Reuse generic resident mechanics; do not alter Bursztynek or garden visitor eligibility/capacity/fair rotation. Ensure cats are not blocked by newly built props; keep collision footprints stable when possible. Generalize save validation/habitat logic that currently assumes bedroom/garden only.
